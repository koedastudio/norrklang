# Code of Conduct

Be kind and stay on topic.

- Assume good faith. Critique code and ideas, never people.
- No harassment, personal attacks, discrimination or trolling — in issues,
  pull requests, commit messages or anywhere else in the project.
- Maintainers may edit or remove content that breaks these rules and block
  contributors who keep breaking them.

Report problems by contacting the maintainers through
[GitHub](https://github.com/koedastudio) or, if public contact is not
appropriate, via
[private reporting](https://github.com/koedastudio/norrklang/security/advisories/new).
Reports are handled confidentially.
